### zsh
- sudo apt install zsh
- sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)" (oh my zsh)
- get config from the .dotfiles github repo
- install oh my zsh plugins found in the .zshrc

### rofi
- sudo apt install rofi
- follow the installation steps from https://github.com/adi1090x/rofi
- copy the entire rofi folder from repo
- fix the missing icons

### polybar
- sudo apt install polybar
- copy the polybar folder from the repo

### picom
- install picom
- copy picom config from the repo

### alacritty
- install alacritty from this repository https://launchpad.net/~aslatter/+archive/ubuntu/ppa
- apt-cache madison alacritty and install the latest version
- copy alacritty config the repo to .config/alacritty/s
- setup alacritty.info for terminfo
